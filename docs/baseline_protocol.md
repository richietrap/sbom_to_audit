# Stage 6.1 Manual-Assisted Matched Baseline Protocol

## Experimental intervention

The intervention is automatic normalization, provenance-linked claim construction, scoped
conflict reasoning, numerical evidence orchestration, clock safeguard, and EvidencePack
assembly. The baseline may use normal inspection tools but may not use those intervention
features.

## Matched conditions

Both workflows receive identical source bytes, event chronology, deadline profile, decision
task, and evidence requirements. Parsing and file inspection are not intentionally made
difficult for the baseline.

## Execution

1. Freeze protocol, oracles, mappings, worksheet schema, and scenario hashes.
2. Export blinded release packets.
3. Complete each event before opening the next release.
4. Record source access, observations, confidence, decisions, conflicts, timing, and rationale.
5. Sign the declaration and record prior automated-output exposure.
6. Hash the original files before normalization.
7. Validate and import the manual records.
8. Run the matched comparison and regenerate candidate paper assets.
9. Reproduce the exact immutable Git commit in Colab.

## Interpretation

Locked metrics remain unchanged. Common-field completeness, partial lineage, conflict
precision, equivalent record-bundle generation, source access, and human Time to Decision
are supplemental controls. The evaluation does not establish legal correctness, industrial
effectiveness, or population-level superiority.
